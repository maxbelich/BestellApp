# 🍔 BurgerHouse Ordering App

BurgerHouse is a responsive ordering app for a fictional restaurant.  
The app displays different food categories such as burgers, pizza and salads. Users can add products to a basket, change item amounts and complete an order.

## 📌 Features

- Dynamic header, hero section and footer
- Food categories and product cards rendered from JavaScript data
- Basket functionality:
  - Add products
  - Increase item amount
  - Decrease item amount
  - Remove products
- Button state for products that are already in the basket
- Mobile cart counter in the bottom navigation
- Basket data saved in LocalStorage
- Free delivery from 50€
- Order confirmation dialog
- Sticky desktop basket
- Mobile basket dialog for smaller screens
- Scrollable basket item list for many products
- Responsive design for desktop, tablet and mobile
- Locally hosted fonts

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
